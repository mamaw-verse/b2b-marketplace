# V1

## Future: Courier integration for delivery confirmation
Phase 3 v1 uses seller-initiated "Mark Delivered" as a manual step. In a future iteration, create a courier entity/partner interface that can confirm delivery via:
- Webhook from courier API (JRS, LBC, J&T, etc.) that auto-transitions fulfilment to 'delivered'
- QR code scan by delivery driver on handover
- Buyer OTP/PIN confirmation at delivery point
This removes the trust gap of seller self-certifying delivery. The fulfilment model already supports this — just add a new actor (courier) that can call the deliver endpoint or a dedicated webhook route.
